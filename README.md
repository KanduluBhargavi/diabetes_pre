# AI Diabetes Risk Analyzer 🧬

An AI-powered Computational Biology web application that predicts diabetes risk using clinical and biological health parameters such as HbA1c, blood glucose, BMI, hypertension, and lifestyle factors.

## Features
- General User Prediction Mode
- Doctor Analysis Mode
- Clinical Risk Prediction
- Gene-Based Risk Assessment
- Lifestyle & Health Recommendations
- Interactive Frontend Interface

## Technologies Used
- Python
- FastAPI
- Scikit-learn
- Pandas & NumPy
- HTML, CSS, JavaScript

## How to Run

1. Install dependencies

pip install -r requirements.txt

2. Start the FastAPI server

uvicorn main:app --reload

3. Open in browser

http://127.0.0.1:8000

Computational Biology + Artificial Intelligence
